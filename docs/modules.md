# 模块设计

## 模块总览

`smalux` 后台重新划分为 10 个主模块：

| 模块 | 优先级 | 目标 |
| --- | --- | --- |
| 总览 | P0 | 展示整体状态、异常、资源趋势和最近事件 |
| 服务器 | P0 | 管理 Agent 接入、分组、标签、状态和密钥 |
| Ping 监测 | P0 | 监测外部地址、端口、延迟、丢包和可用性 |
| 远程执行 | P1 | 支持直接执行、定时执行、执行模板和结果追踪 |
| 通知 | P1 | 管理通知渠道、策略、模板、静默窗口和测试通知 |
| 账户 | P1 | 管理用户、角色、MFA、Passkey 和权限范围 |
| 日志 | P1 | 查看审计日志、执行日志、告警日志和系统日志 |
| 主题 | P1 | 管理后台主题和公开主页主题上传、预览、回滚 |
| 系统设置 | P2 | 管理运行时配置、安全策略、上传限制和保留策略 |
| 部署 | P2 | 支持独立部署、Nginx 部署、Rust Web 内置 |

## 总览

职责：

- 展示服务器在线率。
- 展示 Ping 可用率。
- 展示告警数量。
- 展示远程执行最近失败。
- 展示最近审计事件。
- 展示资源用量趋势。

数据来源：

- HTTP：初始统计。
- WebSocket：实时状态、告警事件、执行事件。

## 服务器

职责：

- 服务器列表。
- Agent 注册。
- Agent Token 创建和吊销。
- Agent 密钥轮换。
- 分组、标签、区域、备注。
- 在线、警告、离线状态。
- CPU、内存、磁盘、网络、负载、延迟。

关键操作：

- 创建注册 Token。
- 吊销 Agent。
- 轮换密钥。
- 删除服务器。
- 移动分组。

安全要求：

- 注册 Token 只展示一次。
- 吊销和删除需要二次确认。
- 密钥轮换写入审计日志。

## Ping 监测

职责：

- 监测 HTTP、TCP、ICMP 或后端支持的探测方式。
- 展示延迟、丢包、可用率。
- 支持探测点分组。
- 支持告警联动。

配置项：

- 目标地址。
- 探测协议。
- 探测间隔。
- 超时时间。
- 重试次数。
- 告警阈值。
- 是否启用。

安全要求：

- 目标地址需要服务端校验。
- 防止 SSRF。
- 限制内网地址探测策略。
- 限制探测频率。

## 远程执行

远程执行必须拆成两个子模块。

### 直接执行

用途：

- 临时执行命令。
- 快速诊断。
- 手动修复。

流程：

1. 选择服务器或分组。
2. 选择命令模板或输入命令。
3. 展示影响范围。
4. 二次确认。
5. 下发执行。
6. 实时查看输出。
7. 记录执行日志和审计日志。

### 定时执行

用途：

- 定时巡检。
- 定时清理。
- 定时脚本。
- 周期性健康检查。

配置项：

- 任务名称。
- 执行目标。
- 命令模板。
- cron 或固定间隔。
- 超时时间。
- 最大并发。
- 失败重试。
- 通知策略。
- 是否启用。

安全要求：

- 禁止无审计执行。
- 命令模板应支持权限范围。
- 高风险命令需要审批或二次确认。
- 输出需要脱敏。

## 通知

职责：

- 通知渠道。
- 通知策略。
- 通知模板。
- 静默窗口。
- 测试通知。
- 通知历史。

渠道：

- Webhook。
- Email。
- Telegram。
- Discord。
- 企业微信。
- 自定义 HTTP。

安全要求：

- Webhook URL 防 SSRF。
- Token 加密存储。
- 测试通知写入审计。
- 限制通知频率。

## 账户

职责：

- 用户列表。
- 角色。
- 权限范围。
- MFA。
- Passkey。
- 会话管理。
- 登录历史。

角色建议：

- Owner。
- Admin。
- Operator。
- Viewer。

权限维度：

- 服务器分组。
- 远程执行。
- 通知配置。
- 主题上传。
- 系统设置。
- 审计日志。

## 日志

日志拆分：

- 审计日志。
- 执行日志。
- 告警日志。
- 通知日志。
- 系统日志。

过滤条件：

- 时间范围。
- 用户。
- 模块。
- 操作类型。
- 资源。
- 成功/失败。

要求：

- 日志不可静默删除。
- 高风险操作必须写日志。
- 支持导出。
- 支持保留策略。

## 主题

职责：

- 后台主题变量配置。
- 公开主页主题包上传。
- 主题参数表单。
- 主题预览。
- 启用、回滚、删除。

主题配置详见 [主题系统](./theme-system.md)。

## 系统设置

设置项：

- 运行时配置。
- 安全策略。
- 主题上传限制。
- Agent 注册策略。
- Ping 探测限制。
- 远程执行限制。
- 日志保留策略。
- 通知频率限制。

要求：

- 所有写操作需要 CSRF。
- 危险设置需要二次确认。
- 设置变更写审计日志。
